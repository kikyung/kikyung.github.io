# N2 일본어 학습 시리즈 작성 규칙

## 파일 구조
- 파일명: `_posts/YYYY-MM-DD-n2-학습-{회차번호}.md`
- 날짜: 이전 회차보다 이후 날짜로 설정
- series: "N2 학습"
- categories: 성장, 일본어
- tags: 일본어

## 단어 테이블 포맷

읽기 컬럼을 별도로 두지 않고, 단어 뒤에 괄호로 읽기를 표기한다.

```markdown
| 단어 | 뜻 | 예문 | 해석 |
|------|-----|------|------|
| 漢字(かんじ) | 뜻 | 예문(후리가나 포함) | 한국어 해석 |
```

## 후리가나 규칙

모든 일본어 예문(테이블 예문 + blockquote 예문)에서 한자 뒤에 `(읽기)` 형태로 후리가나를 표기한다.

- 테이블 예문: `状況(じょうきょう)を正確(せいかく)に把握(はあく)する。`
- blockquote 예문: `> 🗣️ 彼(かれ)がそんなことを言う(ゆう)**わけがない**。`

**bold 처리된 문법 포인트 부분**은 후리가나를 붙이지 않는다.

## 포스트 구성

1. `## 📘 문법:` - N2 문법 1개 (의미, 접속, 예문, 포인트)
2. `## 📝 N2 단어` - N2 레벨 단어 10개 (테이블)
3. `## 🔤 기초 단어 복습 (N3~N5)` - 기초 단어 10개 (테이블)

## 예문 blockquote 형식

```markdown
> 🗣️ 日本語(にほんご)の例文(れいぶん)。
> 한국어 해석.
```
