# AI를 코딩 전문가로 만드는 툴킷

AI 코딩 도구가 넘쳐나는 시대, 세레나는 조금 다른 접근을 합니다. 유료 구독 서비스가 아닌 **무료 오픈소스**로, 여러분이 이미 사용 중인 AI 모델을 진짜 코딩 전문가로 변신시켜주는 강력한 툴킷입니다.



## 1. 세레나란 무엇인가?

세레나는 단순한 AI 챗봇이 아닙니다. 거대 언어 모델(LLM)에게 **'전문가의 눈과 손'**을 달아주는 도구입니다. AI를 단순히 생각만 하는 존재에서, 실제로 코드를 읽고, 수정하고, 명령어를 실행하는 **행동하는 개발자**로 진화시킵니다.

커서(Cursor)나 윈드서프(Windsurf) 같은 유료 서비스와 달리, 세레나는 완전 무료입니다. 이미 사용 중인 LLM의 능력을 추가 비용 없이 극대화할 수 있다는 것이 가장 큰 장점입니다.

## 2. 기술적 차별점: 마스터클래스급 설계

\> 세레나의 핵심은 **LSP(Language Server Protocol)**와 **MCP(Model Context Protocol)**의 결합입니다.

**\- 심볼 단위의 이해(LSP)**: 코드를 단순한 텍스트가 아닌, 함수·클래스·변수 간의 계층 구조와 관계로 파악합니다. 마치 전문 개발자가 코드를 읽는 것처럼 말이죠.

**\- 표준화된 연결(MCP)**: Anthropic이 발표한 Model Context Protocol을 사용해 클로드(Claude) 등 다양한 AI 모델과 외부 도구를 안전하고 효율적으로 연결합니다.

**\- IDE급 도구 제공**: AI가 파일 전체를 읽는 비효율적인 방식 대신, `find_symbol`(특정 심볼 찾기), `find_referencing_symbols`(참조 확인), `insert_after_symbol`(정밀 삽입) 같은 IDE 수준의 정밀한 도구를 사용합니다.

## 3. 왜 세레나를 써야 할까?

**\- 압도적인 토큰 절약**: 필요한 코드 조각만 골라 읽기 때문에 토큰 사용량을 최대 **70%까지 절감**합니다. 이는 비용 절감과 동시에 AI 응답 속도 향상으로 이어집니다.

**\- 정확도 향상**: 대규모 프로젝트에서도 AI가 길을 잃거나 잘못된 정보(환각)를 생성하지 않도록 정밀한 맥락을 제공합니다.

**\- 자율적 문제 해결**: 단순히 코드를 수정하는 데 그치지 않습니다. `execute_shell_command`로 터미널 명령어를 실행하여 테스트를 돌리고 결과를 확인하는 **'계획-빌드-검증' 루프**를 스스로 수행합니다.

## 4. 핵심 워크플로우: 온보딩과 메모리

**\- 온보딩(Onboarding)**: 프로젝트 시작 시 코드를 분석하여 구조를 파악하는 기초 작업입니다.

**\- 메모리(Memories)**: 온보딩 결과와 주요 결정 사항을 `.serena/memories/` 폴더에 Markdown 파일로 저장합니다. 이 메모리는 AI의 **장기 기억 저장소**가 되어, 대화 세션이 바뀌어도 프로젝트의 맥락을 잊지 않고 연속성 있게 작업을 이어갑니다.

## 5. 유연한 확장성

**\- 다양한 환경 지원**: 클로드 코드(Claude Code), 클로드 데스크탑, VS Code, 커서(Cursor), 젯브레인(JetBrains) 등 거의 모든 개발 환경과 연동됩니다.

**\- 방대한 언어 지원**: 파이썬, 자바스크립트, 타입스크립트, 자바, 고(Go), 러스트(Rust), C/C++ 등 **30개 이상의 프로그래밍 언어**를 지원합니다.

**\- 로컬 실행**: 여러분의 컴퓨터에서 직접 실행되므로 코드 보안을 유지하기에 유리합니다.
