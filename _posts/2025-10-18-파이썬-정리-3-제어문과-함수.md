# 제어문과 함수

이 두 개념은 프로그래밍의 기본이자 코드의 재사용성과 가독성을 높이는 핵심 요소입니다.

## 1. 제어문 (Control Flow)

제어문은 프로그램의 실행 흐름을 제어하는 문법입니다. 조건에 따라 다른 코드를 실행하거나, 반복 작업을 수행할 수 있게 해줍니다.

### 1.1 조건문 (if, elif, else)

조건문은 특정 조건이 참일 때만 코드를 실행합니다.

```python
# 기본 조건문
age = 23
if age >= 18:
    print("성인입니다")
else:
    print("미성년자입니다")

# 다중 조건문
score = 85
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"
print(f"학점: {grade}")

# 중첩 조건문
temperature = 25
is_sunny = True

if temperature > 20:
    if is_sunny:
        print("따뜻하고 맑은 날씨")
    else:
        print("따뜻하지만 흐린 날씨")
else:
    print("쌀쌀한 날씨")
```

### 1.2 반복문 (for, while)

반복문은 특정 코드를 여러 번 실행할 때 사용합니다.

#### for 반복문

```python
# 기본 for 반복문
for i in range(5):
    print(f"반복 {i}")

# 리스트 순회
fruits = ["사과", "바나나", "오렌지"]
for fruit in fruits:
    print(f"과일: {fruit}")

# 딕셔너리 순회
person = {"이름": "김철수", "나이": 30, "직업": "개발자"}
for key, value in person.items():
    print(f"{key}: {value}")

# enumerate로 인덱스와 값 함께 사용
for index, fruit in enumerate(fruits):
    print(f"{index + 1}. {fruit}")
```

#### while 반복문

```python
# 기본 while 반복문
count = 0
while count < 5:
    print(f"카운트: {count}")
    count += 1

# 사용자 입력 받기
while True:
    user_input = input("종료하려면 'quit' 입력: ")
    if user_input.lower() == 'quit':
        break
    print(f"입력한 내용: {user_input}")

# 조건부 반복
number = 1
while number <= 10:
    if number % 2 == 0:
        print(f"{number}은 짝수")
    number += 1
```

### 1.3 반복문 제어 (break, continue)

```python
# break: 반복문 즉시 종료
for i in range(10):
    if i == 5:
        break
    print(i)  # 0, 1, 2, 3, 4 출력

# continue: 현재 반복 건너뛰기
for i in range(10):
    if i % 2 == 0:
        continue
    print(i)  # 1, 3, 5, 7, 9 출력
```

## 2. 함수 (Functions)

함수는 특정 작업을 수행하는 재사용 가능한 코드 블록입니다. 코드의 중복을 줄이고 가독성을 높입니다.

### 2.1 기본 함수 정의와 호출

```python
# 기본 함수
def greet():
    print("안녕하세요!")

# 매개변수가 있는 함수
def greet_person(name):
    print(f"안녕하세요, {name}님!")

# 반환값이 있는 함수
def add(a, b):
    return a + b

# 함수 호출
greet()
greet_person("김철수")
result = add(3, 5)
print(f"3 + 5 = {result}")
```

### 2.2 타입 힌트와 기본값

```python
from typing import List, Dict, Optional

# 타입 힌트가 있는 함수
def calculate_area(length: float, width: float) -> float:
    """사각형의 넓이를 계산합니다."""
    return length * width

# 기본값이 있는 함수
def greet_with_greeting(name: str, greeting: str = "안녕하세요") -> str:
    """인사말과 함께 이름을 출력합니다."""
    return f"{greeting}, {name}님!"

# 사용 예시
area = calculate_area(5.0, 3.0)
message = greet_with_greeting("이영희")
custom_message = greet_with_greeting("박민수", "좋은 아침")
```

### 2.3 가변 인자 (\*args, \**kwargs)

```python
from typing import Any

# *args: 위치 인자들을 튜플로 받음
def sum_all(*numbers: float) -> float:
    """여러 숫자의 합을 계산합니다."""
    return sum(numbers)

# **kwargs: 키워드 인자들을 딕셔너리로 받음
def create_profile(**info: Any) -> Dict[str, Any]:
    """사용자 프로필을 생성합니다."""
    return info

# 사용 예시
total = sum_all(1, 2, 3, 4, 5)
profile = create_profile(name="김개발", age=30, job="프로그래머")

# 혼합 사용
def flexible_function(required: str, *args: int, **kwargs: str) -> str:
    result = f"필수: {required}\n"
    result += f"숫자들: {args}\n"
    result += f"키워드들: {kwargs}"
    return result
```

### 2.4 람다 함수 (Lambda Functions)

람다 함수는 간단한 한 줄 함수를 정의할 때 사용합니다.

```python
# 기본 람다 함수
square = lambda x: x * x
print(square(5))  # 25

# 리스트와 함께 사용
numbers = [1, 2, 3, 4, 5]
squared_numbers = list(map(lambda x: x * x, numbers))
print(squared_numbers)  # [1, 4, 9, 16, 25]

# 필터링에 사용
even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
print(even_numbers)  # [2, 4]

# 정렬에 사용
students = [("김철수", 85), ("이영희", 92), ("박민수", 78)]
sorted_students = sorted(students, key=lambda x: x[1], reverse=True)
print(sorted_students)  # 점수 높은 순으로 정렬
```

### 2.5 함수의 고급 기능

```python
# 중첩 함수
def outer_function(x):
    def inner_function(y):
        return x + y
    return inner_function

# 클로저
multiplier = outer_function(10)
result = multiplier(5)  # 15

# 재귀 함수
def factorial(n: int) -> int:
    """팩토리얼을 계산합니다."""
    if n <= 1:
        return 1
    return n * factorial(n - 1)

print(factorial(5))  # 120

# 데코레이터 (간단한 예시)
def my_decorator(func):
    def wrapper(*args, **kwargs):
        print("함수 실행 전")
        result = func(*args, **kwargs)
        print("함수 실행 후")
        return result
    return wrapper

@my_decorator
def say_hello(name):
    print(f"안녕하세요, {name}님!")

say_hello("김철수")
```

## 3. 실용적인 예제

### 3.1 간단한 계산기 함수

```python
def calculator(operation: str, a: float, b: float) -> float:
    """간단한 계산기 함수"""
    if operation == "add":
        return a + b
    elif operation == "subtract":
        return a - b
    elif operation == "multiply":
        return a * b
    elif operation == "divide":
        if b != 0:
            return a / b
        else:
            raise ValueError("0으로 나눌 수 없습니다")
    else:
        raise ValueError("지원하지 않는 연산입니다")

# 사용 예시
try:
    result = calculator("add", 10, 5)
    print(f"10 + 5 = {result}")
except ValueError as e:
    print(f"오류: {e}")
```

### 3.2 데이터 처리 함수

```python
def process_student_grades(grades: List[Dict[str, Any]]) -> Dict[str, Any]:
    """학생 성적을 처리하는 함수"""
    if not grades:
        return {"평균": 0, "최고점": 0, "최저점": 0, "총 학생 수": 0}
    
    scores = [grade["점수"] for grade in grades]
    
    return {
        "평균": sum(scores) / len(scores),
        "최고점": max(scores),
        "최저점": min(scores),
        "총 학생 수": len(grades)
    }

# 사용 예시
student_data = [
    {"이름": "김철수", "점수": 85},
    {"이름": "이영희", "점수": 92},
    {"이름": "박민수", "점수": 78}
]

result = process_student_grades(student_data)
print(result)
```

## 4. 모범 사례

### 4.1 함수 설계 원칙

1. **단일 책임 원칙**: 하나의 함수는 하나의 작업만 수행
2. **명확한 이름**: 함수명만 봐도 기능을 알 수 있게
3. **적절한 크기**: 너무 길면 분리, 너무 짧으면 합치기
4. **타입 힌트 사용**: 매개변수와 반환값의 타입 명시

```python
# 좋은 예
def calculate_discount(price: float, discount_rate: float) -> float:
    """할인된 가격을 계산합니다."""
    if discount_rate < 0 or discount_rate > 1:
        raise ValueError("할인율은 0과 1 사이여야 합니다")
    return price * (1 - discount_rate)

# 나쁜 예
def calc(p, d):
    return p * (1 - d)
```

### 4.2 에러 처리

```python
def safe_divide(a: float, b: float) -> float:
    """안전한 나눗셈을 수행합니다."""
    try:
        if b == 0:
            raise ValueError("0으로 나눌 수 없습니다")
        return a / b
    except TypeError:
        raise ValueError("숫자만 입력 가능합니다")
```
