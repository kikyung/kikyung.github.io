### 왜 사용할까?

* **문제 상황**:

  * 애플리케이션에서 특정 클래스의 인스턴스가 **단 하나만** 존재해야 함
  * 여러 곳에서 같은 객체에 접근해야 하지만, 여러 개의 인스턴스가 생성되면 안 됨
  * 전역 상태를 관리하거나 리소스를 공유해야 할 때
* **해결책**:

  * **private 생성자**로 외부에서 인스턴스 생성을 막음
  * **static 메서드**로 인스턴스에 대한 전역 접근점 제공
  * **static 필드**로 유일한 인스턴스를 보관

### 코드 (db pool 관리등 간단한 패턴이라 아래 예시확인 끝!)

```java
public class Singleton {

  private static final Singleton singleton = new Singleton();

  private Singleton() {
    System.out.println("인스턴스 생성했습니다.");
  }

  public static Singleton getInstance() {
    return singleton;
  }
}
```

```java
public class Main {
    public static void main(String[] args) {
        Singleton obj1 = Singleton.getInstance();
        Singleton obj2 = Singleton.getInstance();
        if (obj1 == obj2) {
            System.out.println("obj1과 obj2는 같은!! 인스턴스.");
        } else {
            System.out.println("obj1과 obj2는 다른 인스턴스.");
        }
    }
}
```
