> 자바스크립트의 **this** 키워드는 종종 개발자들에게 혼란을 줍니다. 호출 방식에 따라 가리키는 대상이 달라지기 때문이죠. 타입스크립트는 이 혼란을 줄이고 `this`를 더 안전하게 다루는 방법을 제공합니다.

## 1. this?

**현재 실행되고 있는 주체**를 가리킵니다. 그 주체는 함수가 어떻게 호출되었는지에 따라 달라집니다.

### 일반 함수 vs. 메서드 호출

* **일반 함수 호출**: `this`는 **전역 객체**를 가리킵니다. (브라우저에서는 `window`, Node.js에서는 `global`)
* **메서드 호출**: `this`는 해당 **메서드가 속한 객체**를 가리킵니다.

```typescript
// 일반 함수 호출
function sayHello() {
  // 전역 객체를 가리킵니다.
  console.log(this); 
}
sayHello();

// 메서드 호출
const user = {
  name: "Kikyung",
  sayName: function() {
    // 'user' 객체를 가리킵니다.
    console.log(this.name); 
  }
};
user.sayName();
```

## 2. 화살표 함수

**`this`** 문제를 해결하는 가장 좋은 방법 중 하나입니다. \
화살표 함수는 자신만의 **`this` 컨텍스트**를 만들지 않고, **상위(렉시컬) 스코프의** `this` **를 그대로 상속** 받습니다.

* this 는 전역(global)을 가르키고 name 속성을 찾을 수 없음

```typescript
const user = {
  name: "Kikyung",
  sayName: function() {
    // sayName의 this는 'user' 객체
    console.log("sayName의 this:", this); 

    setTimeout(function() {
      // 일반 함수는 새로운 this 컨텍스트를 생성.
      // 전역 객체를 가리키므로 this.name은 'undefined'
      console.log("setTimeout 안의 this:", this); 
      console.log(`Hello, my name is ${this.name}`);
    }, 1000);
  }
};
user.sayName();
```

* 콜백 함수를 화살표 함수로 바꾸면, **`sayName`의 `this`를 그대로 물려받아** 의도한 대로 동작합니다.

```typescript
const user = {
  name: "Kikyung",
  sayName: function() {
    // 일반 함수에서는 this가 'user' 객체
    setTimeout(() => {
      // 화살표 함수는 상위 스코프(sayName)의 this를 상속받음
      console.log(`Hello, my name is ${this.name}`);
    }, 1000);
  }
};
user.sayName(); // "Hello, my name is Kikyung"
```

## 3. 명시적 `this` 바인딩

> 강제로 특정 객체에 고정해야 할 필요가 있을때 사용

* **call**(**thisArg, ...args**): 첫 번째 인수로 `this`에 바인딩할 객체를 전달하고, 뒤따르는 인수로 함수 매개변수를 직접 나열합니다.
* **apply**(**thisArg, \[argsArray]**): `call`과 유사하지만, 매개변수를 **배열**로 전달합니다.
* **bind**(**thisArg**): `this`가 고정된 **새로운 함수를 반환**합니다. ***즉시 실행되지 않고, 나중에 호출할 때 사용***

```typescript
function greet() {
  console.log(`Hello, I'm ${this.name}.`);
}

const person1 = { name: "고기경" };
const person2 = { name: "홍기경" };

greet.call(person1); // "Hello, I'm 고기경."
greet.apply(person2); // "Hello, I'm 홍기경."

const boundGreet = greet.bind(person1);
boundGreet(); // "Hello, I'm 고기경."
```

## 4. 타입스크립트의 `this`

#### 안전한 타입 지정

> 타입스크립트는 함수의 첫 번째 매개변수로 **`this`의 타입**을 명시할 수 있도록 지원합니다. 이는 런타임 코드에 영향을 주지 않고, **컴파일 시점에 `this`가 어떤 타입인지** 알려주는 역할을 합니다.

```typescript
interface User {
  name: string;
}

// this의 타입을 User로 명시
function sayName(this: User) {
  console.log(this.name);
}

const user = { name: "Kikyung", sayName };

// 'user' 객체 안에서 호출하므로 정상
user.sayName(); // "Kikyung"

// 오류 발생: 'this' 컨텍스트에 'name' 속성이 없음
// sayName();
```

이렇게 **`this` 타입**을 명시하면, 컴파일러가 잘못된 **`this`** 사용을 미리 잡아내 코드의 안정성을 크게 높일 수 있습니다.
