> 클로저의 개념은 자바(Java)의 내부 클래스(Inner Class)와 매우 비슷합니다. 외부 클래스의 인스턴스 변수에 접근할 수 있는 내부 클래스처럼, 클로저는 자신을 감싸고 있는 외부 함수의 변수에 접근할 수 있는 내부 함수라고 생각하시면 이해가 빠르실 겁니다.

## 클로저의 정의

### 렉시컬 스코프(Lexical Scope)와 상태 유지

* 클로저는 **한마디로 자신이 태어난 곳을 기억하는 함수**입니다.
  함수가 선언될 때의 렉시컬 환경(변수, 함수 선언 등)을 마치 작은 캡슐처럼 가지고 있다가, 나중에 그 함수가 어디서 호출되든 관계없이 그 캡슐 속 환경에 접근할 수 있습니다.
* 예를 들어, Spring에서 `@Component`로 관리되는 A 서비스가 B 서비스를 의존성 주입(DI) 받아 사용하는 것처럼, 클로저 내부 함수는 외부 함수의 변수(상태)를 **주입** 받아 사용하는 것과 같습니다. 이 외부 변수는 함수 호출이 끝난 후에도 사라지지 않고, 클로저가 존재하는 동안 계속 유지됩니다.

### 코드 예시

* 당연히 javascript에 있는 개념

```typescript
function createCounter() {
  let count = 0; 
  
  return function() {
    count++;
    console.log(count);
  };
}
```

* TypeScript에서는 변수에 타입을 명시하여, 더 안전한 코드

```typescript
function createCounter(): () => number {
  // private 변수와 유사
  let count: number = 0;
  
  // 클로저 (내부 함수)
  return function(): number {
    count++;
    return count;
  };
}
const counterA = createCounter(); // 새로운 카운터 인스턴스 생성
counterA(); // 1
counterA(); // 2

const counterB = createCounter(); // 또 다른 독립적인 카운터 인스턴스 생성
counterB(); // 1 (counterA와는 독립적인 상태를 가짐)
```

위 예시에서 `createCounter` 함수가 반환하는 내부 익명 함수가 바로 클로저입니다. 이 클로저는 자신이 선언될 당시의 `count` 변수를 기억하고 있기 때문에, `createCounter` 함수가 이미 종료된 후에도 `count` 변수의 값을 계속해서 증가시킬 수 있습니다.

## 클로저가 유용한 이유: 실용적 관점

1. **데이터 은닉 (Data Encapsulation)**
   외부에서 직접 접근할 수 없는 프라이빗(private) 변수를 만들 수 있습니다. Spring의 `private` 필드처럼, 오직 클로저 내부 함수를 통해서만 해당 변수에 접근하고 조작할 수 있게 됩니다. 이는 객체 지향의 캡슐화 개념과 동일합니다.
2. **상태 유지 (State Preservation)**
   함수 호출 간에도 특정 데이터를 기억하게 하여, 싱글턴 패턴이나 상태를 가지는 객체를 흉내 낼 수 있습니다. 위 카운터 예시처럼, `counterA`와 `counterB`는 각각 독립적인 `count` 상태를 가지고 유지합니다.
3. **함수 팩토리 (Function Factory)**
   매개변수에 따라 다른 동작을 하는 함수를 **만들어내는 공장 역할**을 합니다.
   Spring의 `FactoryBean`처럼, 특정 설정을 주입받아 그 설정에 맞게 동작하는 객체(여기서는 함수)를 생성하는 것과 유사합니다.

```typescript
// 예시: 팩토리 함수
function createLogger(prefix: string) {
  return function(message: string) {
    console.log(`[${prefix}] ${message}`);
  };
}

const networkLogger = createLogger('NETWORK');
const dbLogger = createLogger('DATABASE');

networkLogger('API 요청 성공'); // [NETWORK] API 요청 성공

dbLogger('DB 연결 실패'); // [DATABASE] DB 연결 실패
dbLogger('연결 성공'); // [DATABASE] 연결 성공
```

`createLogger`는 `prefix` 인자를 받아, 그에 맞는 로거 함수를 생성해 반환합니다. 이 반환된 함수(클로저)는 `prefix` 값을 기억하고 있어, 나중에 호출될 때마다 해당 값을 활용합니다.

이처럼 클로저는 JavaScript/TypeScript의 강력한 기능 중 하나로, 객체 지향의 핵심 개념들을 함수형 프로그래밍 방식으로 구현할 수 있게 해줍니다. 처음에는 생소하겠지만, Spring의 개념과 연결해 생각하시면 훨씬 쉽게 다가올 것입니다.
