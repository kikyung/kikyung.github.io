## 어댑터 패턴이란?

서로 호환되지 않는 인터페이스(규격)를 가진 클래스들을 연결해 주는 디자인 패턴이에요. 

쉽게 말해, 모양이 다른 플러그를 콘센트에 꽂을 수 있게 도와주는 전기 어댑터와 같은 역할을 담당합니다.

## 어댑터 패턴을 사용하는 이유

어댑터 패턴은 개발자가 코드를 더 효율적으로 관리하고 유연하게 확장할 수 있도록 도와줘요.

* 재사용성 증가: 기존에 이미 만들어진 코드를 수정하지 않고 그대로 쓸 수 있어요.
* 유연성 향상: 새로운 시스템에서도 이전 클래스들을 쉽게 연결해서 사용할 수 있죠.
* 유지보수 용이: 서로 다른 부분을 어댑터로 분리하면, 나중에 코드를 수정할 때 영향을 받는 부분이 줄어들어 유지보수가 쉬워져요.

## 어댑터 패턴의 구성 요소

어댑터 패턴은 세 가지 주요 구성 요소로 이루어져 있어요. 한국에서 일본으로 여행 가는 상황을 예로 들어볼게요 ✈️

* **Target** (목표 인터페이스): 우리가 현재 사용하려는 방식. 예를 들어, 한국에서 가져온 

  220V 둥근 플러그 형태의 충전기가 되겠죠.
* **Adaptee** (적응 대상 클래스): 이미 가지고 있는 방식. 여행 간 일본의 

  110V 11자 모양의 콘센트를 떠올리면 돼요.
* **Adapter** (어댑터 클래스): Target과 Adaptee 사이를 연결해 주는 중간 역할. 즉, 

  한국 플러그를 일본 콘센트에 맞게 바꿔주는 여행용 어댑터예요.

## 코드로 보는 어댑터 패턴 예제

위에서 설명한 한국-일본 여행 어댑터 예시를 코드로 보여드릴게요.

### 1. Target (목표 인터페이스)

우리가 사용하려는 한국형 충전기 인터페이스예요.

```java
// Target: 현재 220v 충전기만 가지고 있다.
public interface KoreaCharger {
    void plugin();
}
```

### 2. Adaptee (적응 대상 클래스)

이미 존재하는 일본 콘센트 클래스예요.

```java
// Adaptee: 일본여행에 와서 11자 콘센트로 되어있음
public class JapanPlug {
    public void insert11Pin() {
        System.out.println("JapanPlug 11Pin");
    }
}
```

### 3. Adapter (어댑터 클래스)

한국형 충전기를 일본 콘센트에 맞게 변환해 주는 클래스예요.

```java
// Adapter: 둥근 -> 11자 커넥터로 변환
public class KoreaToJapanAdapter implements KoreaCharger {
    private final JapanPlug japanPlug;

    public KoreaToJapanAdapter (JapanPlug japanPlug) {
        this.japanPlug = japanPlug;
    }

    @Override
    public void plugin() {
        this.japanPlug.insert11Pin();
        System.out.println("220v(둥근) -> 110v(11자) 콘센트 변환됨!");
    }
}
```

`KoreaToJapanAdapter` 클래스는 `KoreaCharger` 인터페이스를 구현해서 한국 충전기처럼 동작하게 하지만, 실제 내부에서는 `JapanPlug`를 사용해서 일본 콘센트 규격에 맞춰 변환하는 것을 볼 수 있어요.

### 4. Main (실행)

메인 클래스에서는 어댑터를 사용해서 한국 충전기를 일본 콘센트에 연결해요.

```java
public static void main(String[] args) {
    KoreaCharger koreaCharger = new KoreaToJapanAdapter(new JapanPlug());
    koreaCharger.plugin();
}
```

결과적으로, `koreaCharger.plugin()`을 호출하면 내부적으로 `JapanPlug`의 `insert11Pin()` 메서드가 실행되면서 충전이 가능하게 됩니다.
