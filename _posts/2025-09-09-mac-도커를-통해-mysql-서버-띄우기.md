## **도커로 간단히 mysql 서버 실행, 관리하기**

### 📂 디렉토리 구조 (권장)

```bash
~/docker/mysql/
 ├── docker-compose.yml
 ├── conf.d/
 │    └── my.cnf
 └── data/         (자동 생성, 데이터 영구 저장)
```

### ⚙️ my.cnf 예시

$ vim ~/docker/mysql/conf.d/my.cnf

```ini
[mysqld]
# 기본 문자셋 & 정렬
character-set-server = utf8mb4
collation-server = utf8mb4_general_ci

# 한국 시간대
default-time-zone = '+09:00'

# 느린 쿼리 로그
slow_query_log = 1
slow_query_log_file = /var/lib/mysql/mysql-slow.log
long_query_time = 2

# 안정성/성능 권장값
max_connections = 200
sql_mode = STRICT_TRANS_TABLES,ERROR_FOR_DIVISION_BY_ZERO,NO_ENGINE_SUBSTITUTION
```

- - -

### 📄 docker-compose.yml

$ vim ~/docker/mysql/docker-compose.yml

```yaml
version: "3.9"

services:
  mysql:
    image: mysql:8.4.6
    container_name: mysql8
    restart: unless-stopped
    ports:
      - "3306:3306"
    environment:
      MYSQL_ROOT_PASSWORD: 강력한 비번으로!        # 루트 비밀번호
      MYSQL_DATABASE: appdb                    # 기본 생성 DB
      MYSQL_USER: appuser                      # 앱용 계정
      MYSQL_PASSWORD: 비번지정                   # 앱용 계정 비번
    volumes:
      - ./data:/var/lib/mysql                  # 데이터 영구 저장
      - ./conf.d:/etc/mysql/conf.d             # 설정 파일 반영
```

### 실행

```bash
$ cd ~/docker/mysql
$ docker compose up -d
```

### 확인

```bash
$ docker ps                 # 컨테이너 상태
$ docker logs -f mysql8     # 로그 확인
```

### 정리

* 실행후 Workbench 툴로 접근해보면 잘접근됨을 확인할수 있음!
* 데이터는 `~/docker/mysql/data` 에 영구 보관됨
* 설정은 `~/docker/mysql/conf.d/my.cnf` 로 관리

  * 수정시 `docker compose restart mysql`

끝!
