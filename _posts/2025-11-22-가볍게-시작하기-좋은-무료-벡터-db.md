### 1. Chroma (Chroma DB)

- **특징:**
    - **Python 라이브러리 기반:** 설치 및 사용이 매우 간편합니다. 별도의 서버 설치 없이 Python 애플리케이션 내에서 바로 사용할 수 있습니다.
    - **임베딩 모델 연동 용이:** Hugging Face의 `sentence-transformers` 라이브러리 등 다양한 임베딩 모델과 쉽게 연동할 수 있습니다.
    - **로컬 환경 최적화:** 개발 및 테스트 목적으로 로컬 환경에서 가볍게 사용하기에 정말 좋습니다.
    - **SQL과 유사한 API:** SQL처럼 `add`, `query`, `delete` 등의 명령어로 데이터를 관리할 수 있어 직관적입니다.
    - **오픈 소스:** 무료로 사용할 수 있으며, 커뮤니티 지원도 활발합니다.
- **추천 대상:**
    - Python 기반 애플리케이션 개발자
    - 작은 규모의 데이터셋으로 벡터 검색 실험을 해보고 싶은 분
    - 로컬 환경에서 빠르게 프로토타이핑하고 싶은 분
- **시작 방법:** `pip install chromadb` 명령어로 쉽게 설치할 수 있습니다.

* **Docker**를 통해 로컬에서 간단히 실행해 보자. (실제 설치해보니 현재 v2 버전을 호출해야 정상적으로 사용된다.)

```yaml
    services:
      chromadb:
        image: chromadb/chroma:latest
        container_name: chromadb
        restart: unless-stopped
        ports:
          - "8000:8000"
        environment:
          - IS_PERSISTENT=TRUE
          - ANONYMIZED_TELEMETRY=FALSE
          # 인증 비활성화 (학습용) - 프로덕션에서는 인증 활성화 권장
          # - CHROMA_SERVER_AUTHN_PROVIDER=chromadb.auth.token_authn.TokenAuthenticationServerProvider
          # - CHROMA_SERVER_AUTHN_CREDENTIALS=test-token
          # - CHROMA_SERVER_AUTHN_TOKEN_TRANSPORT_HEADER=X-Chroma-Token
        volumes:
          - ./data:/chroma/chroma
        healthcheck:
          test: ["CMD", "curl", "-f", "http://localhost:8000/api/v2/heartbeat"]
          interval: 30s
          timeout: 10s
          retries: 3
          start_period: 40s
```


### 2. Qdrant

- **특징:**
    - **고성능:** Rust로 작성되어 속도가 빠르고 효율적입니다.
    - **다양한 배포 옵션:**
        - **로컬 실행:** Docker를 사용하거나 바이너리 파일을 다운로드하여 로컬 환경에서 실행할 수 있습니다.
        - **클라우드 서비스:** 무료 티어를 제공하는 클라우드 서비스도 있어, 서버 관리 없이 사용할 수도 있습니다.
    - **강력한 기능:** 필터링, 정렬, 페이징 등 다양한 검색 옵션을 지원합니다.
    - **간편한 REST API:** 다양한 프로그래밍 언어에서 HTTP 요청으로 쉽게 접근할 수 있습니다.
- **추천 대상:**
    - 로컬 환경 또는 Docker 환경에서 실행 가능한 솔루션을 찾는 분
    - 조금 더 확장성 있고 성능 좋은 솔루션을 원하는 분
    - 다양한 언어에서 API 접근을 원하는 분
- **시작 방법:** Docker `docker run qdrant/qdrant` 명령어로 쉽게 실행하거나, 클라우드 서비스를 이용할 수 있습니다.

### 3. Weaviate (Cloud Native Vector Database)

- **특징:**
    - **클라우드 네이티브 설계:** Kubernetes 환경에 최적화되어있지만, Docker로도 쉽게 로컬에서 실행 가능합니다.
    - **데이터 처리 및 벡터화 기능 통합:** 간단한 경우, Weaviate 자체에서 일부 임베딩 모델을 연동하여 데이터 저장과 동시에 벡터화를 수행할 수 있습니다.
    - **GraphQL API 지원:** GraphQL API를 제공하여 데이터 검색 및 관리가 유연합니다.
    - **강력한 검색 및 분석 기능:** 여러 벡터 검색 방법, 필터링, 거리 측정 방식 등을 지원합니다.
    - **오픈 소스 & 상용 버전:** 오픈 소스 버전으로 무료 사용이 가능하며, 추가 기능/지원 등을 위한 상용 버전도 있습니다.
- **추천 대상:**
    - 컨테이너 환경(Docker, Kubernetes)에 익숙하신 분
    - 데이터 저장부터 벡터화까지 통합적으로 관리하고 싶은 분
    - GraphQL API에 익숙하신 분
- **시작 방법:** Docker `docker run -p 8080:8080 weaviate/weaviate:latest` 명령어로 실행할 수 있습니다.

### 어떤 것을 선택하면 좋을까요?

- **Python으로 빠르게 시작하고 싶다면:** **Chroma**가 가장 쉽고 빠르게 첫걸음을 뗄 수 있게 해줍니다.
- **조금 더 성능 좋고 유연한 사용을 원한다면:** **Qdrant**를 추천합니다. Docker 실행이 어렵지 않다면 좋은 선택입니다.
- **컨테이너 기반 환경에 익숙하고 다양한 기능을 원한다면:** **Weaviate**를 고려해 보세요.

처음에는 Chroma로 시작해서 벡터 검색의 기본적인 개념을 익히시고, 필요에 따라 Qdrant나 Weaviate와 같은 더 강력한 솔루션으로 확장해 나가는 것을 추천합니다.
