## 🚀 주요 신기능

### 1. Composer 1 Alpha: 차세대 코딩 AI 모델

Cursor가 자체 개발한 새로운 AI 모델 **Composer 1 Alpha**가 출시되었습니다.

**핵심 특징:**
- **독립성 강화**: 외부 모델(GPT-4, Claude 등) 의존도를 크게 낮춤
- **압도적인 속도**: 동급 지능 수준의 모델 대비 **4배 빠른 응답 속도**
- **다중 파일 편집**: 여러 파일을 동시에 수정하고 관리하는 작업에 최적화

기존에는 외부 AI 모델에 의존했다면, 이제 Cursor 자체 모델로 더 빠르고 효율적인 코딩이 가능해졌습니다.

---

### 2. 멀티 에이전트 시스템

여러 AI 에이전트가 동시에 작업할 수 있는 혁신적인 시스템이 도입되었습니다.

**작동 방식:**
- **Git work trees 활용**: 각 에이전트가 독립된 작업 공간에서 작업하여 코드 충돌 방지
- **병렬 작업 가능**: 한 에이전트가 백엔드 작업을 하는 동안, 다른 에이전트는 프론트엔드 작업 수행
- **빠른 전환**: `Command + E` 단축키로 에디터와 뷰 간 즉시 전환

복잡한 프로젝트에서도 여러 작업을 동시에 진행할 수 있어 개발 속도가 비약적으로 향상됩니다.

---

### 3. 내장 브라우저 (Browser Tool)

에디터 내부에 브라우저가 직접 통합되어 웹 개발이 한층 편리해졌습니다.

**주요 기능:**
- **실시간 프리뷰**: 코드 변경 사항을 즉시 브라우저에서 확인
- **Element 선택 도구**: DOM 요소를 클릭하면 해당 정보가 AI 에이전트에게 자동 전달
- **개발자 도구**: Chrome과 유사한 디버깅 도구 내장
- **스크린샷 캡처**: 화면을 찍어 채팅 컨텍스트에 추가하여 AI와 시각적 소통 가능

프론트엔드 개발자라면 필수적인 기능으로, 에디터와 브라우저를 오가는 번거로움이 사라집니다.

---

### 4. 음성 입력 기능

타이핑 없이 음성으로 코드를 작성하고 AI를 제어할 수 있습니다.

**활용 방법:**
- **음성 → 텍스트 변환**: 마이크로 말하면 자동으로 텍스트로 변환되어 에이전트에게 전달
- **핸즈프리 코딩**: 손을 다쳤거나, 타이핑이 불편한 상황에서도 코딩 가능
- **빠른 지시**: 긴 설명을 타이핑하는 대신 말로 빠르게 요구사항 전달

"이 함수에 에러 핸들링을 추가해줘"라고 말하면, AI가 즉시 코드를 수정합니다.

---

### 5. 개선된 워크플로우 및 UI

작업 효율성을 극대화하는 다양한 UI 개선이 이루어졌습니다.

**변경 사항 통합 뷰:**
- 여러 파일에 걸친 수정 사항을 **한 곳에서 모두 확인**
- 작업 완료 후 채팅 창에 나타나는 **Review 버튼**을 클릭하면 모든 변경 사항을 한눈에 검토 가능
- 파일 간 이동 없이 승인/거부 결정

**Changes 패널:**
- 좌측 패널 상단의 **Changes** 섹션에서 커밋 메시지 자동 생성
- **Agent Review** 기능으로 AI가 작성한 코드에 대한 리뷰 요청 가능

## 🔧 핵심 기능

### Memories (자동 규칙 생성)

프로젝트별로 자동으로 학습하고 규칙을 생성하는 지능형 메모리 시스템입니다.

**작동 원리:**
1. **사이드카 관찰**: 백그라운드에서 다른 모델이 대화를 관찰하며 패턴 학습
2. **자동 메모리 추출**: 사용자의 코딩 스타일, 선호하는 라이브러리, 명명 규칙 등을 자동 추출
3. **사용자 승인 필요**: 생성된 메모리는 저장 전 사용자 승인을 받아 신뢰성 보장
4. **도구 호출**: AI가 중요하다고 판단한 정보는 명시적으로 메모리 생성 요청

프로젝트를 진행할수록 AI가 여러분의 코딩 스타일을 더 잘 이해하게 됩니다.

---

### Codebase Indexing

코드베이스 전체를 학습하여 맥락을 이해합니다.

**특징:**
- `.gitignore`, `.cursorignore`에 포함된 파일을 제외한 **모든 파일 인덱싱**
- 프로젝트 구조와 코드 간의 관계를 파악하여 더 정확한 제안 제공
- [공식 문서](https://docs.cursor.com/ko/context/ignore-files)에서 파일 무시 설정 방법 확인 가능

## 🔒 보안 및 엔터프라이즈 기능

### 팀 커맨드 (Team Commands)

**대시보드에서 중앙 관리:**
- 팀 전용 커스텀 명령 및 코딩 규칙을 정의
- 모든 팀원에게 자동 적용되어 일관성 유지
- 팀의 코딩 컨벤션을 AI가 자동으로 따르도록 설정

---

### 샌드박스 터미널 (GA)

**보안 강화:**
- 터미널이 작업 공간에 대한 **읽기/쓰기 권한만** 보유
- **인터넷 접근 권한 없음**: 악의적인 코드 실행 위험 최소화
- 민감한 프로젝트에서도 안전하게 AI 터미널 사용 가능

## 기타: 과금관련 의문 ㅎㅎ

Cursor Pro 플랜을 사용하면서 추가 과금이 발생하지 않는 이유

### 기본 포함 사항

**월 $20 구독료에 포함:**
- **$20 상당의 LLM 크레딧**: AI 모델 사용을 위한 토큰 크레딧 제공
- **토큰 기반 계산**: 요청 횟수가 아닌 실제 토큰 소비량으로 측정
- **무제한 Auto 모드**: 비용 효율적인 모델을 자동 선택하는 Auto 모드는 추가 비용 없음
- **무제한 탭 완성**: 코드 자동 완성 기능은 크레딧 소모에 거의 영향 없음

### 추가 과금이 발생하는 경우

포함된 **$20 크레딧을 모두 소진**한 후에만 종량제 요금(On-demand usage)이 부과됩니다.

**크레딧 소모가 큰 작업:**
- GPT-4, Claude Opus 같은 고급 모델 빈번한 사용
- 매우 긴 컨텍스트(대용량 파일) 처리
- Agent Max 모드로 복잡한 작업 반복 수행

**크레딧 절약 팁:**
- **Auto 모드 활용**: 작업에 따라 최적의 저비용 모델 자동 선택
- **탭 완성 우선 사용**: 간단한 코드 작성은 탭 완성으로 해결
- **컨텍스트 최적화**: 불필요한 파일은 인덱싱에서 제외

대부분의 일반적인 사용자는 **포함된 $20 크레딧 내에서 충분히 사용** 가능하므로, 추가 과금을 걱정할 필요가 없습니다.
