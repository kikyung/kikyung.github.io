> TypeScript의 튜플(Tuple) 타입은 고정된 길이와 타입을 가진 배열입니다. 
> 일반 배열과 달리 **각 위치에 정확한 타입을 지정할 수 있어서 데이터의 구조를 명확하게 표현**할 수 있습니다.

## 1. 기본 튜플 타입

튜플의 기본 문법은 `[타입1, 타입2, ...]` 형태입니다.

```typescript
// 기본 튜플 타입
let nameAndAge: [string, number] = ["홍길동", 25];
let coordinates: [number, number] = [10, 20];
let rgbColor: [number, number, number] = [255, 128, 0];
```

* `nameAndAge`: \[이름, 나이] 형태의 튜플
* `coordinates`: \[X좌표, Y좌표] 형태의 튜플  
* `rgbColor`: \[빨강, 초록, 파랑] RGB 색상 튜플

## 2. 튜플 요소 접근과 수정

튜플의 요소는 배열처럼 인덱스로 접근하고 수정할 수 있습니다.

```typescript
// 요소 접근
console.log("이름:", nameAndAge[0]);  // "김기경"
console.log("나이:", nameAndAge[1]);  // 20

// 요소 수정
nameAndAge[0] = "김기경";
nameAndAge[1] = 20;
```

## 3. 읽기 전용 튜플 (Readonly Tuple)

`readonly` 키워드를 사용하면 튜플의 요소를 수정할 수 없습니다.

```typescript
let readonlyTuple: readonly [string, number] = ["읽기전용", 100];
// readonlyTuple[0] = "수정불가"; // ❌ 컴파일 에러!
```

## 4. 선택적 요소가 있는 튜플

`?` 연산자를 사용하여 선택적 요소를 만들 수 있습니다.

```typescript
let optionalTuple: [string, number?] = ["필수", 42];
let optionalTuple2: [string, number?] = ["필수만"]; // 두 번째 요소 생략 가능
```

## 5. 나머지 요소가 있는 튜플

`...타입[]`을 사용하여 가변 길이의 튜플을 만들 수 있습니다.

```typescript
let restTuple: [string, number, ...string[]] = ["첫번째", 1, "추가1", "추가2", "추가3"];
```

## 6. 복잡한 튜플 타입

`type` 키워드를 사용하여 재사용 가능한 튜플 타입을 정의할 수 있습니다.

```typescript
type Point3D = [number, number, number];
type PersonInfo = [string, number, string]; // [이름, 나이, 직업]

let point3D: Point3D = [10, 20, 30];
let personInfo: PersonInfo = ["Eddie", 30, "Engineer"];
```

## 7. 튜플을 사용한 함수 반환값

함수에서 여러 값을 반환할 때 튜플을 활용할 수 있습니다.

```typescript
function getUserInfo(): [string, number, string] {
  return ["Steven", 30, "Designer"];
}

function getCoordinates(): [number, number] {
  return [Math.random() * 100, Math.random() * 100];
}
```

## 8. 튜플 구조 분해 (Destructuring)

튜플의 요소를 개별 변수로 분해할 수 있습니다.

```typescript
let [name, age] = nameAndAge;
let [x, y] = coordinates;
let [r, g, b] = rgbColor;

console.log("구조 분해된 이름:", name);
console.log("구조 분해된 나이:", age);
```

## 9. 튜플의 실제 사용 사례

### API 응답 데이터

```typescript
type ApiResponse = [boolean, string, any?];
let successResponse: ApiResponse = [true, "성공", { data: "결과" }];
let errorResponse: ApiResponse = [false, "에러 발생"];
```

* 첫 번째 요소: 성공/실패 여부
* 두 번째 요소: 메시지
* 세 번째 요소: 데이터 (선택적)

## 10. 튜플 vs 배열의 차이점

```typescript
let tuple: [string, number] = ["hello", 10];
let array: (string | number)[] = ["hello", 10];
```

| 특징     | 튜플  | 배열  |
| ------ | --- | --- |
| 길이     | 고정  | 가변  |
| 타입 순서  | 엄격  | 자유  |
| 타입 안전성 | 높음  | 낮음  |

## 11. 튜플 사용 시 주의사항

1. **타입 순서 엄격**: 각 위치의 타입을 정확히 지켜야 합니다
2. **길이 제한**: 정의된 길이를 초과하면 타입 에러가 발생할 수 있습니다
3. **가독성**: 복잡한 튜플은 인터페이스나 클래스로 대체하는 것이 좋습니다

## 마무리

TypeScript 튜플은 다음과 같은 상황에서 유용합니다:

* **좌표 데이터**: `[x, y]`, `[x, y, z]`
* **키-값 쌍**: `[key, value]`
* **함수 반환값**: 여러 값을 한 번에 반환
* **API 응답**: 성공/실패 상태와 데이터를 함께 표현

튜플을 적절히 활용하면 코드의 타입 안전성을 높이고 데이터 구조를 명확하게 표현할 수 있습니다. \
하지만 너무 복잡한 튜플은 가독성을 떨어뜨릴 수 있으니, 상황에 맞게 사용하는 것이 중요합니다.
