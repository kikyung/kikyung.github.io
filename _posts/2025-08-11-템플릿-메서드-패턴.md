## ***TemplateMethod Pattern*** 이란?

> 템플릿 메서드 패턴은 **알고리즘의 뼈대(흐름)**를 상위 클래스에서 정의하고, 그 일부 단계의 구현은 하위 클래스에서 바꾸는 디자인 패턴이에요.  

마치 식당에서 요리를 할 때, `재료 준비 → 조리 → 그릇에 담기 → 서빙` 이라는 전체적인 순서는 항상 같지만, 어떤 요리(김치찌개, 파스타)를 만드냐에 따라 `조리` 방법만 다르게 하는 것과 비슷하죠

## 템플릿 메서드 패턴을 쓰는 이유

이 패턴을 사용하면 여러 장점을 얻을 수 있어요.

* **코드 중복 제거:** 공통된 작업 흐름을 상위 클래스에 한 번만 정의해서 , 하위 클래스에서 코드를 복사해서 붙여넣을 필요가 없어져요.
* **일관성 유지**: 전체적인 작업 순서가 상위 클래스에 고정되어 있기 때문에 모든 하위 클래스가 동일한 흐름을 따르게 돼요.
* **유연하고 쉬운 유지보수**: 알고리즘의 뼈대(템플릿 메서드)는 수정하지 않고, 세부 단계만 하위 클래스에서 오버라이드하면 되므로, 새로운 기능을 추가하거나 수정할 때 유지보수가 쉬워져요.

## 템플릿 메서드 패턴의 구조

이 패턴은 크게 추상 클래스와 구상 클래스(하위 클래스)로 구성돼요.

* **추상 클래스 (AbstractClass)**: 알고리즘의 전체 흐름을 정의하는 **템플릿 메서드**와, 각 단계를 나타내는 메서드들을 선언해요. 이 중 일부 단계 메서드는 하위 클래스에서 구현하도록 **추상 메서드**로 만들 수 있어요. 템플릿 메서드는 하위 클래스에서 오버라이드하지 못하도록 `final` 키워드를 사용하는 것이 좋아요.
* **구상 클래스 (ConcreteClass)**: 추상 클래스를 상속받아 , 추상 메서드로 선언된 단계들을 오버라이드해서 자신만의 방식으로 구현해요.

## Java 코드 예제: 식당 요리 시스템

식당에서 다양한 요리를 만드는 과정을 템플릿 메서드 패턴으로 구현

### 1. 추상 클래스 `Dish`

요리의 전체적인 흐름을 정의하는 추상 클래스예요.

```java
abstract class Dish {
    // 템플릿 메서드: 요리 전체 과정, final로 오버라이드를 막습니다!
    public final void makeDish() {
        prepareIngredients(); // 공통 단계
        cook();               // 하위 클래스에서 다르게 구현할 단계
        plate();              // 공통 단계
        serve();              // 공통 단계
    }

    // 공통 단계들
    void prepareIngredients() {
        System.out.println("재료를 준비합니다.");
    }
    void plate() {
        System.out.println("그릇에 담습니다.");
    }
    void serve() {
        System.out.println("손님에게 서빙합니다.");
    }

    // 요리마다 다르게 구현할 부분 (추상 메서드)
    abstract void cook();
}
```

### 2. 구상 클래스 `KimchiStew`와 `Pasta`

`Dish` 클래스를 상속받아 `cook()` 메서드를 각 요리에 맞게 구현해요.

```java
class KimchiStew extends Dish {
    @Override
    void cook() {
        System.out.println("김치와 돼지고기를 넣고 푹 끓입니다.");
    }
}

class Pasta extends Dish {
    @Override
    void cook() {
        System.out.println("면을 삶고 소스를 넣어 볶습니다.");
    }
}
```

### 3. 실행

메인 클래스에서 각 요리 객체를 만들고, `makeDish()` 메서드를 호출하면 정해진 순서대로 요리가 만들어져요.

```java
public class Main {
    public static void main(String[] args) {
        Dish kimchiStew = new KimchiStew();
        kimchiStew.makeDish();

        System.out.println("\n---\n");

        Dish pasta = new Pasta();
        pasta.makeDish();
    }
}
```

**출력 결과**는 `KimchiStew` 객체와 `Pasta` 객체 모두 `prepareIngredients`, `plate`, `serve`는 공통으로 실행하고, `cook`만 다르게 실행되는 것을 확인할 수 있어요

템플릿 메서드 패턴을 잘 활용하면 코드의 **유지보수성과 확장성**을 크게 높일 수 있습니다.
