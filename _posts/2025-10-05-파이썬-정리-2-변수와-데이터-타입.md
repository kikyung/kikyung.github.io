> 파이썬은 동적 타입핑(Dynamically Typed) 언어로, 변수 선언 시 타입을 명시할 필요가 없어 유연합니다. 그러나 프로젝트 규모가 커질수록 이 유연함이 혼란을 야기할 수 있으므로, 본 회차에서는 **타입 힌트(Type Hint)**를 활용하여 가독성과 유지보수성을 확보하는 방법을 함께 다룹니다.

## 1. 기본 타입: 숫자, 문자열, 불린

파이썬은 별도의 선언 없이 변수에 값을 할당하면 해당 값의 타입으로 자동 결정됩니다. 그러나 **가독성 향상을 위해 타입 힌트를 적용하는 것을 권장**합니다.

### 1.1. 숫자 (`int`, `float`)

정수와 실수 타입을 나타냅니다. 파이썬은 정수의 크기에 제한이 없어 메모리가 허용하는 한 무한한 정수를 다룰 수 있습니다.

```python
# 숫자와 문자열: 타입 힌트 (Type Hinting) 적용 예시
price: float = 19.99  # 실수형
qty: int = 3          # 정수형

# 연산 후 반올림 (결과: 59.97)
print(round(price * qty, 2))
```

### 1.2. 문자열 (`str`)

텍스트 데이터를 나타냅니다. f-string(`f"..."`)은 문자열 포매팅을 매우 간결하고 직관적으로 처리할 수 있게 해주는 핵심 기능입니다.

```python
name: str = "파이썬"
# f-string을 이용한 변수 삽입 (결과: 안녕하세요, 파이썬!)
print(f"안녕하세요, {name}!")
```

## 2. 컬렉션 타입: 데이터 구조화의 핵심

리스트, 딕셔너리, 튜플, 집합은 데이터를 효율적으로 관리하고 조작하는 데 사용됩니다.

### 2.1. 리스트 (`list`): 가변(Mutable) 순차 컬렉션

가장 흔하게 사용되는 컬렉션으로, 순서가 있으며(Ordered), 요소의 추가, 삭제, 수정이 자유롭습니다(Mutable).

#### 슬라이싱 (Slicing)

리스트의 특정 구간을 잘라내어 새로운 리스트를 생성하는 기법입니다. 문법은 `list[시작 인덱스:끝 인덱스:간격]`이며, 끝 인덱스 요소는 포함되지 않음을 반드시 유의해야 합니다.

```python
nums: list[int] = [1, 2, 3, 4, 5, 6]
## 0부터 시작이고 끝인덱스는 제외한다는 부분을 주의하자!
print(nums[1:4])  # 결과: [2, 3, 4] (인덱스 1, 2, 3)
print(nums[0:4])  # 결과: [1, 2, 3, 4]
```

#### 리스트 컴프리헨션 (List Comprehension)

기존 리스트를 기반으로 새로운 리스트를 간결하게 생성하는 문법입니다. 가독성을 높이고 코드를 압축합니다.

```python
# nums 리스트에서 짝수만 추출하여 evens 리스트 생성
evens: list[int] = [n for n in nums if n % 2 == 0]  # 결과: [2, 4, 6]
```

### 2.2. 딕셔너리 (`dict`): 키-값(Key-Value) 구조

키(Key)와 값(Value)의 쌍으로 데이터를 저장하며, 키를 통해 O(1) 시간 복잡도로 빠르게 데이터를 검색할 수 있습니다.

#### 안전 접근: `.get()` 메서드

키가 존재하지 않을 경우를 대비하여 에러(`KeyError`)를 방지하고 기본값을 설정할 수 있는 `.get()` 메서드 사용이 권장됩니다.

```python
user: dict[str, str] = {"name": "kikyung", "email": "a@example.com"}

# 키가 없을 경우 "등록 없음" 반환 (결과: 등록 없음)
print(user.get("phone", "등록 없음"))

# 기본값을 안 주면 → None 반환 (결과: None)
print(user.get("phone"))

# 주의: []로 접근 시 키가 없으면 에러 발생
# print(user["phone"])  # KeyError: 'phone'
```

### 2.3. 튜플 (`tuple`): 불변(Immutable) 순차 컬렉션

리스트와 유사하나 **불변(Immutable)**합니다. 한 번 생성되면 요소 수정이 불가능하며, 주로 함수에서 여러 값을 반환할 때 사용됩니다.

#### 언패킹 (Unpacking) 및 스왑

튜플 요소를 여러 변수에 한 번에 할당하는 언패킹은 파이썬에서 매우 유용합니다.

```python
pt: tuple[int, int] = (10, 20)
x, y = pt   # 언패킹 (결과: 10 20)
print(x, y)

# 변수 스왑 (자주 사용됨): 임시 변수 없이 두 변수 값 교환
x, y = y, x  # x=20, y=10으로 값이 변경됨

# *를 사용한 나머지 요소 할당
a, *rest = (1, 2, 3, 4)  # a=1, rest=[2, 3, 4]
```

### 2.4. 집합 (`set`): 중복 없는 컬렉션

집합은 순서가 없고(Unordered), 중복되는 요소를 허용하지 않는 컬렉션 타입입니다. 이 특성 덕분에 리스트 등 다른 컬렉션에서 중복을 빠르게 제거하거나, 두 데이터 그룹 간의 수학적 집합 연산(∪,∩,∖)을 수행할 때 매우 효율적입니다. 요소의 존재 여부 확인이 빠르다는 장점도 있습니다.

```python
# 집합 생성 및 중복 자동 제거
data_list = [1, 2, 2, 3, 4, 4, 5, 5, 5]
unique_data: set[int] = set(data_list)
print(unique_data)  # 결과: {1, 2, 3, 4, 5}

# 집합 연산: 합집합, 교집합, 차집합
set_a: set[int] = {1, 2, 3, 4, 5}
set_b: set[int] = {4, 5, 6, 7, 8}

# 1. 합집합 (Union): | 연산자 또는 .union() 메소드 사용
# A와 B에 속한 모든 요소 (결과: {1, 2, 3, 4, 5, 6, 7, 8})
print(set_a | set_b)
print(set_a.union(set_b))

# 2. 교집합 (Intersection): & 연산자 또는 .intersection() 메소드 사용
# A와 B에 공통으로 속한 요소 (결과: {4, 5})
print(set_a & set_b)
print(set_a.intersection(set_b))

# 3. 차집합 (Difference): - 연산자 또는 .difference() 메소드 사용
# A에 속하지만 B에는 속하지 않는 요소 (결과: {1, 2, 3})
print(set_a - set_b)
print(set_a.difference(set_b))
```

## 3. 타입 힌트 (Type Hint): 가독성을 위한 선택

파이썬의 동적 타입핑은 개발 속도를 높이지만, 대규모 협업 프로젝트에서는 변수의 타입을 명시하는 것이 중요합니다. 타입 힌트는 런타임에 영향을 주지 않으며, 개발 도구(IDE)가 오류를 미리 찾거나 코드를 이해하는 데 도움을 줍니다. 이는 주석처럼 타입 정보를 제공하여 코드의 가독성과 유지보수성을 획기적으로 향상시킵니다.

```python
# 변수 할당 시: 변수명: 타입 = 값
qty: int = 3

# 함수 정의 시: 매개변수: 타입 -> 반환타입
def calculate_total(price: float, qty: int) -> float:
    return price * qty
```

타입 힌트는 이제 파이썬 코딩의 표준 관행입니다. 지금부터 타입 힌트 사용을 습관화하는 것을 강력히 권장합니다.
