### TypeScript 역할!

* TypeScript는 동적 언어인 JavaScript에 Java와 같은 정적 타입 시스템을 도입한 언어
* `NullPointerException` 같은 런타임 오류를 개발 단계에서 미리 잡아낼 수 있어 코드의 안정성 향상
* 명시적인 타입은 코드의 가독성을 높여주고, 대규모 프로젝트에서 협업하는 팀원들과의 소통 비용 감소
* 결국 개발자가 버그를 쫓는 시간을 줄여, 비즈니스 로직에 더 집중하게 만들어주는 강력한 도구!



### 1. 선택 속성 (Optional Property) `?:`

인터페이스를 정의할 때, 특정 속성이 필수값이 아닐 경우 `?`를 붙여준다.
이게 없으면 개발자가 매번 속성값을 다 넣어줘야 하니 효율적으로 사용할수 없음

```typescript
interface Person {
  name: string;
  age?: number; // age는 선택사항
}
```

### 2. 접근 제한자 (Access Modifier)

클래스 속성 앞에 붙는 `public`, `private`, `protected`를 말한다.
아무것도 안 붙이면 **`public`**이 기본값이다.

* `public`: 어디서든 접근 가능
* `private`: 클래스 내부에서만 접근 가능
* `protected`: 클래스 내부 + 상속받은 자식 클래스에서 접근 가능

### 3. 추상 클래스 (Abstract Class)

`abstract class`로 정의하며, 직접 인스턴스를 만들 수는 없다. 오로지 상속을 위해 존재한다.
추상 클래스 안의 추상 속성이나 메서드는 자식 클래스가 반드시 구현해야 한다.
정해진 형태를 강제할 때 유용하다.

```typescript
abstract class AbstractPerson {
  abstract name: string; // 자식 클래스에서 반드시 구현
}
```

### 4. 잔여 연산자 (Rest Operator)

객체나 배열에서 특정 속성들을 제외한 나머지를 싹 모아준다.

```typescript
const { country, city, ...detail } = address;
// country와 city를 제외한 나머지가 detail에 들어감
```

### 5. 전개 연산자 (Spread Operator)

잔여 연산자와 반대로, 객체나 배열의 내용을 펼쳐서 새로운 객체나 배열에 복사할 때 쓴다.
데이터 불변성을 유지하며 새로운 객체를 만들 때 아주 유용하다.

```typescript
let merged = { ...part1, ...part2, ...part3 };
// part1, part2, part3의 속성이 하나로 합쳐짐
```

### 6. 타입 캐스팅 (Type Casting)

객체의 타입을 내가 알고 있는 더 구체적인 타입으로 '단언'하는 행위.
`<Type>변수` 또는 `변수 as Type` 형식으로 사용한다.
타입스크립트가 추론하지 못하는 타입을 개발자가 직접 알려줄 때 쓴다.

```typescript
let person: object = { name: 'jack', age: 23 };
console.log((<{ name: string }>person).name);
```
