### 왜 사용할까?

**문제 상황**:

* 한 객체의 상태가 변경될 때, 그 객체에 의존하는 여러 객체들이 각각 업데이트되어야 함
* 객체 간의 결합도가 높아져서 유지보수가 어려움
* 새로운 관찰자를 추가하거나 제거할 때 기존 코드를 수정해야 함

**해결책**:

* Subject(주체)와 Observer(관찰자)를 분리
* Subject는 자신을 관찰하는 Observer들의 목록을 관리
* Subject의 상태가 변경되면 등록된 모든 Observer들에게 자동으로 통지

### 유튜브 채널 구독 예시로 이해하기

1. **발행자 (Subject)**: **유튜브 채널** (예: 에디의 코딩교실)
2. **구독자 (Observer)**: **채널 구독자들**

새로운 영상이 올라오면, 유튜브 채널이 곧바로 모든 구독자에게 알림을 보내게 됩니다

* **구독 신청**\
  구독자가 채널에 들어가서 **'구독'** 버튼을 누르면, 유튜브는 이 사용자를 **'구독자 목록'**에 추가합니다. 이 과정이 바로 **옵저버를 발행자에게 등록**하는 거예요.
* **새 영상 업로드**\
  채널 주인이 새로운 영상을 올리면, 채널의 **'상태'**가 **'새 영상 업로드'**로 변경돼요.
* **알림 발송** \
  채널은 자신의 상태가 변했으니, 구독자 목록에 있는 모든 사람에게 알림을 보냅니다. \
  이 과정이 바로 **옵저버들에게 통지(Notify)**하는 거죠.
* **알림 수신:** 구독자들은 이 알림을 받고 **'새로운 영상이 올라왔구나'**라는 사실을 알게 됩니다.

> 여기서 중요한 점은 **유튜브 채널(발행자)**은 구독자가 누구인지, 그리고 그들이 알림을 받아서 뭘 할지에 대해서는 전혀 몰라요. \
> 그냥 **구독자 목록에 있는 모든 사람에게 알림을 보내**라고만 하면 끝이에요.\
> 이처럼 **발행자와 구독자가 서로 느슨하게 연결되어 있다는 것이** 옵저버 패턴의 핵심입니다

* 채널(발행자)은 구독자가 100명이든 10만 명이든 상관없이, 새로운 영상만 올리면 됩니다.
* 구독자(옵저버)는 채널이 무슨 기술로 영상을 만들었는지 알 필요 없이, 알림만 받으면 됩니다.

이런 구조는 시스템의 유연성을 높이고, 한쪽이 변경되어도 다른 쪽에 영향을 미치지 않게 해줍니다.

### 다이어그램

![](/assets/img/uploads/observer_youtube_uml.svg "observer_youtube")

이 다이어그램에서 **`CodePartnerChannel` (발행자)**은 **`Subscriber` (구독자)**들에게 알림을 보내고, 각 **사용자(옵저버)**는 **`YoutubeChannel`**을 구독하는 관계를 시각적으로 보여줍니다.

### 1. 발행자(Subject)와 옵저버(Observer) 인터페이스 정의

```java
// 발행자(Subject): 구독자를 관리하고 통지하는 역할
public interface YoutubeChannel {

    void registerSubscriber(Subscriber s);
    void removeSubscriber(Subscriber s);
    void notifySubscribers(String videoTitle);
}

// 옵저버(Observer): 발행자의 상태 변화를 통지받는 역할
public interface Subscriber {

    void update(String channelName, String videoTitle);
}
```

### 2. 구체적인 발행자 클래스 (유튜브 채널)

`YoutubeChannel` 인터페이스를 구현하여 구독자를 관리하고 새로운 영상을 업로드할 때 통지하는 기능을 추가합니다.

```java
import java.util.ArrayList;
import java.util.List;

public class CodePartnerChannel implements YoutubeChannel {

    private List<Subscriber> subscribers = new ArrayList<>();
    private String channelName;

    public CodePartnerChannel(String channelName) {
        this.channelName = channelName;
    }

    @Override
    public void registerSubscriber(Subscriber s) {
        subscribers.add(s);
        System.out.println(s.getClass().getSimpleName() + "님이 " + channelName + " 채널을 구독했습니다.");
    }

    @Override
    public void removeSubscriber(Subscriber s) {
        subscribers.remove(s);
        System.out.println(s.getClass().getSimpleName() + "님이 " + channelName + " 채널 구독을 취소했습니다.");
    }

    @Override
    public void notifySubscribers(String videoTitle) {
        System.out.println("\n--- [" + channelName + "] 새 영상 업로드: '" + videoTitle + "' ---");
        for (Subscriber subscriber : subscribers) {
            subscriber.update(channelName, videoTitle);
        }
    }

    // 채널의 상태를 변경하는 메소드 (새 영상 업로드)
    public void uploadNewVideo(String videoTitle) {
        notifySubscribers(videoTitle);
    }
}
```

### 3. 구체적인 옵저버 클래스 (구독자)

`Subscriber` 인터페이스를 구현하여 통지를 받았을 때 수행할 작업을 정의합니다.

```java
public class User implements Subscriber {
    private String name;

    public User(String name) {
        this.name = name;
    }

    @Override
    public void update(String channelName, String videoTitle) {
        System.out.println("알림: " + name + "님! " + channelName + " 채널에 새 영상 '" + videoTitle + "'가 올라왔습니다!");
    }
}
```

### 4. 실행 클래스 (실제 사용 예시)

발행자(`CodePartnerChannel`)를 만들고, 옵저버(`User`)들을 등록하고, 상태 변화를 일으키는 과정을 보여줍니다.

```java
public class YoutubeDemo {
    public static void main(String[] args) {
        // 1. 유튜브 채널(발행자) 생성
        CodePartnerChannel myChannel = new CodePartnerChannel("코딩 파트너");

        // 2. 사용자들(옵저버) 생성 및 채널에 등록
        User user1 = new User("김기경");
        User user2 = new User("김에디");
        
        myChannel.registerSubscriber(user1);
        myChannel.registerSubscriber(user2);

        // 3. 채널 상태 변경 (새 영상 업로드), 자동으로 구독자들에게 알림
        myChannel.uploadNewVideo("디자인 패턴 정복");
        
        // 4. 한 명의 구독자가 구독 취소
        myChannel.removeSubscriber(user2);

        // 5. 또 다른 새 영상 업로드, 남아있는 구독자에게만 알림
        myChannel.uploadNewVideo("Spring Boot 시작하기");
    }
}
```
